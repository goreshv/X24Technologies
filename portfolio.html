Problem Statement: A high-volume transactional database table with over 4.5 million records was locking during daily reporting queries, causing production timeouts, 95% CPU spikes, and severe lock escalations.
Solution Overview: Identified missing composite indexes using Extended Events and Query Store. Re-engineered correlated subqueries into Common Table Expressions (CTEs), introduced filtered indexes on status flags, and updated index statistics with a targeted maintenance job.

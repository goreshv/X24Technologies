/* BEFORE: Correlated subquery causing table scan */
SELECT o.Id, o.Total, (SELECT COUNT(*) FROM Items i WHERE i.OrderId = o.Id) ...
-- Scan Count: 48,200 | Logical Reads: 1,842,000 | CPU: 7,420ms | Duration: 8,140ms
/* AFTER: Refactored with Window Function & Covering Index */
CREATE NONCLUSTERED INDEX IX_Items_OrderId_Inc ON Items(OrderId) INCLUDE (Price, Status);
WITH OrderCounts AS ( SELECT OrderId, COUNT(*) AS ItemCount FROM Items GROUP BY OrderId ) ...
-- Scan Count: 1 | Logical Reads: 4,120 | CPU: 82ms | Duration: 94ms
>> Result: 98.8% reduction in execution time & eliminated blocking locks.

Pragmatic Modernization Strategy

1
Dependency & Portability Audit: Identify third-party libraries, Windows-specific APIs, and architectural bottlenecks before writing migration code.
2
Incremental Strangler Fig Pattern: Migrate endpoints and services incrementally rather than attempting a risky "big bang" rewrite that stalls business operations.
3
Linux Containerization: Package modernized services into lightweight Linux containers, dramatically reducing hosting and Windows licensing overhead.
